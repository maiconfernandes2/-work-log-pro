# Work Log Pro

Work Log Pro is an iPhone app that helps workers track their daily work hours quickly and easily.

## Features

- Clock In
- Break Start
- Break End
- Clock Out
- Save job address
- GPS location
- Weekly hours summary
- Overtime calculation
- Dark Mode
- Export timesheet to PDF

## Future Features

- iCloud Sync
- Face ID protection
- Multiple jobs
- Paycheck calculator
- Calendar view
